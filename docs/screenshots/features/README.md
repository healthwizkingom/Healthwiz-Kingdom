# HealthWiz Kingdom — feature screenshots

**Not shown / limits:** camera pulse, Bluetooth heart rate, GPS, motion sensor, microphone, AI chat, food search and drink photo scan (need hardware, sign-in or internet); the Campus map and weather are blank because the page ran offline from a file; badges/XP are inflated by the demo seed.
