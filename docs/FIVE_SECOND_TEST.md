# Five-second test script (not run yet)

This test needs real people, so it has not been run. Run it on the Home screen, the Health Score and the Stairs page, at
360 x 640 and 390 x 844, in at least Arcane Night and Parchment.

1. Show the screen for five seconds, then hide it (turn the phone face down or close the tab).
2. Ask, without looking again: "What was this page for?", "What is the first thing you would tap?", "What number or word
   stood out most?", "Was there anything you could not read?"
3. Write each answer down word for word. Do not explain or lead.
4. Pass: at least four of five people say the page is about health tracking (not a game), find the health panel or score first,
   and name no unreadable text. Note which element they named as first for the hierarchy check (health panel strongest,
   quests and game progress weakest).
5. Preference test: show the before and after screenshots (`docs/screenshots/`) side by side in random order and ask which is
   easier to read. Record the choice and the reason.
